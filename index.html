Learn the भगवद्गीता, two ways

Same ten verses, two very different ways to learn them. Try the guided path if you want small daily steps with checks along the way; open the study reader if you would rather sit with each verse and take it apart word by word. Both are live below — pick either and start.

A Duolingo-style trail through the chapter's opening — one verse per stop, a few minutes each.

Option A — The Guided Path

Ten stops, one for each verse. Each lesson now has four short steps, almost all in Sanskrit: पाठः (read and tap the words), पदपरिचयः (is each word a नामपदम् or a क्रियापदम्?), अन्वयः with the कारकचक्रम्, and a final परीक्षणम् (meaning check). Every stop stays open, so you can revisit any verse.

Which one fits you?

They teach the same verses. The difference is the rhythm.

Guided Path

Pace
One verse at a time, about 2–3 minutes a stop; all ten verses in roughly half an hour, or spread over days.
You do
Read, tap words for meanings, answer one check per verse. The path decides what comes next.
Choose it if
You are starting out, or you want the Gita to become a daily habit that carries you forward on its own.

Study Reader

Pace
Yours. Sit with a single verse for twenty minutes, or scan all ten in five.
You do
Read the full analysis — every word glossed, the context explained — and move freely between verses.
Choose it if
You already read some Sanskrit, are preparing for a class, or want a reference to return to.
